# 🚀 Acore — Все для вас

**Acore** — це вебплатформа, оптимізована для роботи на смартфонах, ПК та розумних годинниках (Samsung Galaxy Watch тощо). Вона поєднує інтерактивний ШІ-чат, новини, поштовий сервіс, перекладач та мініігри проти штучного інтелекту.

---

## 🌟 Основні можливості

- 🤖 **Чат із ШІ:** Підтримка кількох моделей (Groq API, OpenRouter API: `openai/gpt-oss-20b`, `llama-3.3-70b-versatile`, `llama-3.1-8b-instant`, `gemma2-9b-it`) з автоматичним фолбеком.
- 📰 **Новини:** Актуальні новини України в реальному часі (RSS).
- 📧 **Пошта:** Вхід/реєстрація через Acore, Gmail, Outlook, перегляд та надсилання листів.
- 🌐 **Перекладач:** Швидкий переклад тексту через MyMemory API.
- 🎮 **Ігри проти ШІ:** 
  - ❌/⭕ **Хрестики-Нулики** (із розумним ШІ та рахунком).
  - 🏓 **Пінг-Понг** (із підтримкою тачскріна).
  - 💣 **Сапер** (із цифрами підказок).
- ⛅ **Віджети:** Погода у Черкасах та курс валют НБУ.
- 💳 **Монетизація / Підтримка:** Пряме посилання на банку Monobank.

---

## 🛠️ Технології

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS).
- **APIs:** 
  - Groq / OpenRouter API (ШІ)
  - MyMemory API (Переклад)
  - Open-Meteo API (Погода)
  - НБУ API (Курси валют)
  - RSS2JSON (Новини)

---

## 📱 Оптимізація

Сайт має повністю адаптивний дизайн під екрани від **280px до 340px** (для smart-годинників) та вище.

---

## 🚀 Запуск проєкту

1. Клонуйте або завантажте репозиторій.
2. Відкрийте `index.html` у будь-якому браузері.
3. Додаткових залежностей чи збірки не потрібно!
