# Acore Search & Maps

**Pошук та карти від Acore Corp.**

Два HTML файли в одному сайті:
- 🔍 **index.html** — Пошук (Google-подібний)
- 🗺️ **maps.html** — Карти (OpenStreetMap)

---

## 📁 Структура

```
Acore-Search/
├── index.html   (пошук - головна, з вкладеними стилями)
├── maps.html    (карти, з вкладеними стилями)
├── search.js    (логіка пошуку)
├── maps.js      (логіка карт)
└── README.md    (цей файл)
```

**Кожен HTML файл — автономний, без зовнішніх залежностей (окрім CDN для Leaflet).**

## 🚀 Запуск

### Локально (простіше всього)

```bash
# Python 3
python -m http.server 8000

# Або Python 2
python -m SimpleHTTPServer 8000

# Або Node.js
npx http-server
```

Потім відкрий http://localhost:8000

### На хостингу (GitHub Pages, Netlify, Vercel)

1. Закинь папку на хостинг
2. Всё готово! (потребы лишь статические файлы)

## 🔍 Функціонал

### Пошук (index.html)
- Введи запит у пошукову стрічку
- Результати з демо-бази або посилання на Google
- Кнопка "Мені Пощастить" — перехід на перший результат

**Демо запити:**
- "привіт"
- "україна"
- "javascript"
- "acore"

### Карти (maps.html)
- 🗺️ Карта України з OpenStreetMap
- 📍 10 популярних міст
- 🔍 Пошук міста за назвою
- 📱 Кнопка "Моя позиція" (якщо дозволиш геолокацію)
- 🎯 Клік на результат = перехід на місто

**Міста:**
- Київ, Львів, Харків, Одеса, Дніпро
- Запоріжжя, Полтава, Кременчук, Черкаси, Чернівці

## 🔄 Як розширяти

### Додати свої результати пошуку
Відредагуй `search.js` та добавь нові ключі в об'єкт `mockResults`:

```javascript
const mockResults = {
    'моя тема': [
        {
            title: 'Назва',
            url: 'https://example.com',
            description: 'Опис'
        }
    ]
};
```

### Додати більше міст на карту
У `maps.js` додай до об'єкту `cities`:

```javascript
const cities = {
    'назва': { lat: 50.0, lng: 30.0, name: 'Назва міста' }
};
```
